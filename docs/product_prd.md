## 1. 产品概述

### 1.1 一句话定位
**面向小众兴趣群体的"LBS + IP 标签"陌生人社交 App，专注把线上同好匹配转化为线下聚会社交。**

### 1.2 产品愿景
让每一个拥有小众爱好的人，都能在身边找到"懂我的人"，并把"线上聊得来"升级为"线下玩得到"。

### 1.3 核心差异化
| 维度 | 活动行 | 小红书 | **本产品** |
| --- | --- | --- | --- |
| 平台定位 | 泛活动信息聚合 | 泛兴趣生活社区 | **娱乐类垂直同好匹配** |
| 用户发现 | 关键词搜索 | 内容推荐流 | **LBS + IP 标签双重匹配** |
| 社交关系 | 弱（活动结束即散） | 弱（基于内容） | **强（同好关系沉淀）** |
| 兴趣颗粒度 | 行业活动级 | 生活方式级 | **IP 级（具体作品/角色）** |
| 用户人群 | 商务/参会者 | 大众女性 | **内向/宅家/小众爱好者 + 出海社群运营** |

### 1.4 商业模式探索（远期，本期不实现）
- 会员订阅：解锁无限匹配、隐身访问、身份徽章
- 活动票务抽佣：5% 平台服务费
- B 端 SaaS：面向出海游戏/动漫公司的海外社群代运营后台
- 品牌联名：IP 周边商城抽佣

## 2. 目标用户

### 2.1 核心用户画像

**画像 A：内向宅家小众爱好者（小 A，22 岁）**
- 喜欢二次元、galgame、视觉小说，追冷门番剧
- 工作日宅家刷推，社交圈狭窄
- 渴望"不尬聊"的同好社交：希望先看对方兴趣再决定是否接触
- 痛点：豆瓣小组只能线上聊，B 站/微博的同好都在千里之外

**画像 B：线下活动组织者（小 B，26 岁）**
- 桌游店店长 / Coser / 剧本杀 DM
- 经常需要拉人凑局，但很难触达精准人群
- 痛点：朋友圈发活动 1 小时阅读 5 个、报名 0 个

**画像 C：出海 IP 社群运营（运营 C，28 岁）**
- 某出海游戏公司用户运营，需要在海外建立核心粉丝社群
- 痛点：Discord/Telegram 用户活跃度低，无法从线上延伸到线下

### 2.2 用户规模假设（远期）
- 6 个月内：5 万注册、1 万 DAU
- 12 个月内：30 万注册、8 万 DAU
- 24 个月内：100 万注册、25 万 DAU

### 2.3 关键使用场景
1. **匹配场景**：打开 App → 看附近同好 → 按兴趣筛选 → 看到匹配度高的人
2. **破冰场景**：匹配成功后不知道聊啥 → 系统推送共同 IP 作为话题 → 自然开聊
3. **组局场景**：想玩剧本杀但凑不齐人 → 发起活动 → 邀请匹配到的同好 → 线下聚会签到
4. **运营场景**（B 端）：运营在后台创建品牌活动 → 用户报名 → 活动现场用户沉淀到私域

## 3. 核心功能详述

### 3.1 IP 标签体系（基础设施）

**目的**：将抽象的兴趣具象化为可匹配的结构化标签

**分类设计**：
- **游戏**：原神 / 王者荣耀 / 明日方舟 / 赛马娘 / 喷射战士 / 我的世界 / 黑神话悟空
- **影视**：流浪地球 / 哈利波特 / 漫威 / 复仇者联盟 / 灌篮高手
- **动漫/番剧**：孤独摇滚 / 葬送的芙莉莲 / 进击的巨人 / 间谍过家家
- **漫画/轻小说**：海贼王 / 咒术回战 / Overlord / 弹丸论破
- **其他**：模型手办 / Vtuber / 同人创作 / Live 演出

**展示规则**：
- 每个用户最多选择 5 个一级 IP 标签 + 3 个二级角色/作品标签
- 主页标签墙以霓虹 Chip 形式展示，可点击查看相同标签的同好
- 标签热度按"同好数 × 7 天增长率"排序

**本期实现**：
- 预置 60+ IP 标签（每个分类 12-15 个）
- 支持搜索 + 多选 + 拖拽排序
- Chip 支持"发光"动效强调

### 3.2 LBS 附近同好发现

**目的**：让"同好"在地理维度上从抽象到具体

**本期实现（Mock）**：
- 内置 50 个虚拟用户，坐标围绕深圳南山区（22.5429, 113.9414）±0.05° 抖动
- 通过 Haversine 公式计算距离，按距离 + 匹配度综合排序
- 顶部筛选条支持"1km / 5km / 10km / 全城"半径切换
- 列表模式：垂直卡片流，左滑跳过 / 右滑发起聊天
- 地图模式：附近用户用发光圆点（颜色按兴趣分类），活动用菱形 pin

**远期实现**：
- 接入高德/腾讯定位 SDK
- 位置模糊化处理（隐私保护）：返回 500m 精度而非精确位置
- 后台常驻定位 + 地理围栏触发推送

### 3.3 标签匹配推荐

**目的**：从"按距离排序"升级为"按契合度排序"

**匹配算法（本期 Mock）**：
```
match_score = 0.6 * 共同IP标签数 / 5 + 0.3 * (1 - 距离/最大半径) + 0.1 * 活跃度
```

**展示**：
- 卡片正面显示"匹配度 87%"霓虹大字
- 共同 IP 标签用高亮 Chip 区分
- 距离显示在右下角，精确到 100m

### 3.4 推荐 Feed 流

**目的**：除 LBS 外，让用户发现同城/同好的内容动态

**Feed 内容类型（本期 Mock）**：
- 帖子：文字 + 图片 + IP 标签
- 活动预告：海报 + 时间 + 报名 CTA
- 同好推荐：卡片式（与发现页一致）

**排序规则**：基于"同 IP 标签 > 同城 > 7 天内热度"

### 3.5 1v1 IM 聊天

**目的**：把"匹配"转化为"关系"

**本期实现**：
- 文字消息：双向气泡（自己右侧霓虹渐变，对方左侧玻璃拟态）
- 图片消息：缩略图 + 点击放大（mock 占位图）
- 系统消息：自动推送共同 IP 作为破冰话题
- 模拟对方回复：通过 `Timer` 延迟 1-3s 推送预置回复文案
- 会话列表：按最近消息时间排序，未读数红点

**远期实现**：
- 语音消息、表情包
- 接入腾讯云 IM SDK，支持消息漫游、推送
- 敏感词过滤 + 举报机制

### 3.6 线下活动中心

**目的**：把"线上的关系"转化为"线下的体验"

**活动状态机**：`招募中 → 已成行 → 进行中 → 已结束 → 已签到`

**核心字段**：
- 标题、封面图、IP 分类、时间、地点（地图选点）
- 主办人、参与上限、参与列表、签到状态
- 费用、备注、标签

**操作流**：
- 用户 A 发布活动 → 系统推送附近同好 → 用户 B 报名 → 自动加入聊天群组 → 活动当天签到

## 5. 用户故事（精选）

### US-01：注册选标签
> **作为**新用户小 A
> **我希望**首次注册时选择 3-5 个 IP 标签
> **以便**系统能立刻给我推荐匹配度最高的附近同好

**验收**：
- [ ] 注册流强制走完标签选择才能进入主页
- [ ] 至少 1 个最多 5 个标签
- [ ] 支持搜索 + 分类切换
- [ ] 选择后主页 Feed 第一屏至少 3 个匹配度 > 60% 的用户

### US-02：发现附近同好
> **作为**想找同好的小 A
> **我希望**在附近 Tab 看到 5km 内有相同 IP 标签的用户
> **以便**周末约出来面基

**验收**：
- [ ] 列表/地图两种视图可切换
- [ ] 距离、匹配度、IP 标签一目了然
- [ ] 卡片左滑跳过、右滑发起聊天

### US-03：发起线下活动
> **作为**桌游店店长小 B
> **我希望**在活动 Tab 发布"周六剧本杀"活动
> **以便**让有相同爱好的陌生人报名

**验收**：
- [ ] 表单支持标题、封面、分类、时间、地点（地图选点）、描述
- [ ] 发布后出现在活动 Tab 顶部
- [ ] 推送给附近有相关 IP 标签的用户
- [ ] 用户报名后自动加入活动群

### US-04：聊天破冰
> **作为**匹配到同好的小 A
> **我希望**系统自动推荐"你们都喜欢的 IP 话题"
> **以便**避免尬聊开场白

**验收**：
- [ ] 首次进入聊天页时弹出系统卡片"你们都喜欢：原神"
- [ ] 点击可一键发送预设话题消息

### US-05：语言切换
> **作为**海外华人用户
> **我希望**一键切换中英文
> **以便**把 App 推荐给外国朋友

**验收**：
- [ ] 设置页有中/英 SegmentedControl
- [ ] 切换后整个 App 所有文案立刻更新
- [ ] 选择持久化到本地，重启 App 仍生效


## 8. 风险与对策

| 风险 | 等级 | 对策 |
| --- | --- | --- |
| LBS 模拟不够"真" | 中 | 预置 50 个高质量 mock 用户，IP 标签/简介/头像多样化 |
| IM 演示效果单薄 | 中 | 预置 8-10 段不同风格的对方回复 + 1 段带图片消息 |
| 演示视频观感一般 | 中 | 使用 Lottie 强动效 + 录屏剪辑 + 赛博 BGM |
| 后期接入真实后端改动大 | 低 | Repository 层抽象 + DataSource 接口预留 |
| 美术风格与产品调性不符 | 中 | 设计令牌（颜色/字体/圆角/阴影）集中管理，便于美术后续替换 |

## 10. 附录

### 10.1 名词解释
- **IP 标签**：用户对特定作品/角色/品牌的兴趣标识（IP = Intellectual Property）
- **LBS**：Location Based Service，基于地理位置的服务
- **同好**：拥有相同兴趣爱好的人
- **同好度**：基于 IP 标签重合度计算的匹配分

### 10.2 竞品参考
- 国外：Tapple、Vibe、Bumble BFF
- 国内：Soul（语音匹配）、积目（兴趣卡）、开 PA（剧本杀）
- 垂直社区：豆瓣小组、百度贴吧兴趣吧
