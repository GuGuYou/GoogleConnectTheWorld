# 基于LBS的匿名兴趣陪伴社交产品项目交付包

## 项目基本信息

- **项目内容**：基于LBS的匿名兴趣陪伴社交产品Demo开发
- **制定时间**：2026.7.2
- **角色分工**：PM范闲（进度管理/对接美工）、技术3人（私下分工）、美工1人（外部，7.8后介入UI）
- **报名截止**：7.12（不赶ddl）

## 核心产品定位与理念

- **一句话定位**：基于LBS的匿名兴趣陪伴社交产品，让用户在擦肩而过中发现同好，在异步留言中感受"你不是孤身一人"
- **核心理念**：坚持真善美，做温暖陪伴而非歧途交友
- **灵感来源与借鉴**：
  - **明日方舟爆火视频**：借鉴身边擦肩而过同好提示，用LBS+兴趣标签匹配，附近出现同好时提示
  - **光遇**：借鉴匿名虚拟形象、温馨陪伴，提供捏脸/AI生成小人，降低社交压力
  - **死亡搁浅**：借鉴异步留言、跨时空陪伴，支持在地点留下文字/语音，供未来的人查看

## 目标用户

**共性**：不是不想社交，是没找到合适的打开方式

- **异乡漂泊者（留学生/新移民/外出工作）**：核心场景为刚到陌生城市未建立社交圈，痛点是身边没人懂自己的小众爱好
- **社交困难/内向/情绪困扰群体**：核心场景为想联系外界但不适应大众社交，痛点是真实身份社交压力太大
- **小众兴趣爱好者**：核心场景为追冷门剧/游戏/CP，痛点是找不到同好、产粮没人看

## 核心功能规划（只做3个）

1. **匿名身份："你不是你，你是你的热爱"**
   - 用户注册后创建虚拟形象，支持两种方式：模板选+简单自定义（颜色、配饰，P0）、上传照片/关键词AI生成（亮点，P1）
   - 需要设置兴趣标签（游戏/动漫/影视/CP）
   - 明确不做：实名认证、复杂个人资料、社交关系链（替代产品很多）
2. **LBS同好雷达："擦肩而过的缘分"**
   - 开启App后通过Google Map获取GPS定位
   - 在地图上显示附近（可调半径，如3km）有相同Tag的用户，以虚拟形象（小人/光点）展示
   - Filter机制：只显示与自己有相同兴趣的人，避免信息过载
   - 明确不做：实时聊天室、复杂匹配算法、距离精确到米（保留空间）
3. **异步留言墙："你不是孤身一人"**
   - 参考《死亡搁浅》异步机制，用户可在当前地点留下文字/语音留言
   - 其他用户路过同一地点时能看到历史留言，呈现"曾经有X个人在这里，和你有相同的Tag，他们留下了这些话"
   - 营造温暖回忆录体验
   - 明确不做：实时消息、好友系统、私信（后续入围再说）

## 明确砍掉的功能

| 砍掉功能 | 砍掉理由 |
| --- | --- |
| 一起看电影/同屏观影 | 技术验证卡顿严重，偏离产品方向 |
| 语音聊天室 | 偏向实时社交，与"异步陪伴"方向冲突 |
| 入门问卷答题 | 匿名温暖方向不需要门槛筛选 |
| 中英双语切换 | Demo阶段先做中文，不分散精力 |
| 房间管理/踢人/转让 | 产品不再设计房间概念 |
| 表情动作/虚拟小屋3D | 2D足够，3D太费时间 |

## 技术需求总览

### 技术栈选型

- **前端**：Web（移动端适配），先做Web版不做原生App
- **地图**：Google Map API（大赛要求必须接入）
- **AI生成**：Gemini API（生成虚拟小人形象）
- **后端**：轻量级（Node/Python均可），存储用户、Tag、留言、位置
- **数据库**：轻量级（SQLite/Firebase均可），满足Demo级别需求

### 模块优先级划分

- **P0核心模块**：用户注册登录、模板创建虚拟形象、兴趣Tag设置、Google Map接入、GPS定位、同好标记、兴趣Filter、Mock数据、留言功能、查看留言、所有核心前端页面
- **P1亮点模块**：AI生成形象、半径筛选、统计展示、留言列表排序

### 关键风险应对

- **Google Map API接入慢**：7.5需要跑通，跑不通用静态地图+假定位降级
- **AI生成小人做不出**：降级为模板选择，不死磕
- **GPS定位不准**：Demo可接受误差，用Mock数据辅助
- **多人同时在线卡顿**：Demo用Mock数据，不需要真实多人

## 美术需求总览

- **介入时间**：7.8后开始
- **风格要求**：温暖、治愈、匿名、轻盈、不冰冷，参考光遇的温馨感 + Pokemon Go的地图交互 + 死亡搁浅的留言温度
- **核心交付时间节点**：7.8交付登录/形象/Tag页设计、基础小人模板、配色字体规范；7.9交付App图标、启动页插画、地图/留言页设计、配饰素材、光点样式
- **主色调要求**：温暖色系（暖黄/暖橙/淡粉），不用冷色调
